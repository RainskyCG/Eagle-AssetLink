# Eagle AssetLink 1.0.0 使用说明

**本地资产浏览器**

项目原名 Eagle Bridge。升级保留原插件 ID、EagleBridge 数据目录及已有 EagleBridge 关联标签，无需重新建立关联。

Windows / Eagle 4 本地资产浏览插件。通过 Everything 查找源文件，在 Eagle 中关联目录、浏览文件和预览内容。

## 安装与配置

1. 双击发布文件 `Eagle-AssetLink-1.0.0.eagleplugin`，在 Eagle 中确认安装。也可解压同名 ZIP，通过「插件 → 开发者选项 → 导入本地项目」选择包含 manifest.json 的目录。
2. 从插件菜单打开 Eagle AssetLink。
3. 自行安装 [Everything](https://www.voidtools.com/downloads/) 和 [ES 命令行工具](https://www.voidtools.com/support/everything/command_line_interface/)，或使用插件中的官方自动配置功能。
4. 在配置中选择 Everything.exe、es.exe，检测并连接，然后添加资产库目录。
5. 等待 Everything 完成索引。网络/NAS 目录需要先加入 Everything 的文件夹索引；仅配置插件路径不会建立索引。
6. 选择 Eagle 素材，使用右侧「定位」或「展开」。名称清理和定位优先级可在设置中调整。

**发布包和源码包不包含 Everything.exe、es.exe、语言包、索引数据库、个人配置或下载缓存。** 保留插件的检测、连接与官方自动配置代码。

## 浏览与操作

- 多个匹配目录分组展示，可选择并关联。没有本地匹配时显示 Eagle 素材磁盘上的 `.info` 文件夹列表，该区域只读。
- 中央面板提供路径输入、搜索、筛选、排序，以及详细列表、水平列表、缩略图视图。搜索仅针对当前列表。
- Ctrl 增减选、Shift 连选、空白区域拖动框选。Ctrl+滚轮或顶部滑条调整视图。
- 右键可打开、定位、重命名、删除、新建文件夹及调整视图。删除支持多选，确认后移入系统回收站，保留 Eagle 资产；失败不转为永久删除。
- 双击文件夹进入；双击文件可在设置中选择默认应用打开或资源管理器定位。
- 中央顶栏右侧按钮展开预览/详情。拖动左边界与上下分隔线调整大小。

## 预览

图片支持滚轮缩放、拖动平移、双击复位。PDF 使用 Eagle 原生查看器；各格式优先使用已启用的格式查看器插件，无可用插件时尝试 Eagle 原生预览。音视频依赖 Eagle 原生播放器，部分其他格式显示静态预览图。

ZIP 下方显示目录和文件，上方预览所选条目，切换目录保留预览。普通图片在内存读取，单张最多 16 MB；其他可预览文件按需读取单个条目到临时目录，最多 256 MB，切换或关闭后清理。不会整包解压或执行包内文件。加密 ZIP、RAR、7z 暂不支持；包内模型所需的外部材质可能缺失。

依赖真实 Eagle 资产 ID 的第三方插件不保证能读取未导入的本地文件。格式支持与编码能力跟随已安装的 Eagle 和查看器版本，不能保证所有格式均成功预览。

## 快捷键

| 按键 | 功能 |
| --- | --- |
| Ctrl+Alt+L / Ctrl+Alt+E | 定位 / 展开（插件有焦点时） |
| Alt+← / Alt+→ / Alt+↑ | 后退 / 前进 / 上一级 |
| F5 | 刷新 |
| Ctrl+L / Ctrl+F | 地址栏 / 搜索 |
| F2 / Ctrl+Shift+N | 重命名 / 新建文件夹 |
| Ctrl+滚轮 | 显示模式和尺寸 |
| Esc | 关闭菜单或预览，再返回 Eagle |

由 Eagle 管理的快捷键可通过开发者选项导入 `shortcuts/locate` 和 `shortcuts/expand`，再在 Eagle 快捷键设置中绑定。子入口依赖相对路径，保留主插件与 shortcuts 的原有目录结构。

`shortcuts/rename` 和 `shortcuts/delete` 是可选同步操作，会涉及关联目标及 Eagle 条目，与列表中的本地删除不同，操作前有明确路径确认。

## 更新与排查

安装新版本或重新加载本地项目后，关闭并重新展开中央面板。若旧版本仍驻留，可重启 Eagle。设置保存在 Eagle 用户数据目录的 `EagleBridge/state.json`，更新时保留，发布时不上传。

更换电脑需重新指定工具路径、资产目录和失效关联。当前仅支持 Windows。中央面板依赖 Eagle 内部接口，Eagle 升级后可能需要适配。

搜索失败先检查 Everything 是否独立搜得到文件；预览失败检查格式插件是否启用及支持本地路径。反馈请附 Eagle/插件版本、格式、操作步骤与提示，不要提交索引数据库或私有素材。
